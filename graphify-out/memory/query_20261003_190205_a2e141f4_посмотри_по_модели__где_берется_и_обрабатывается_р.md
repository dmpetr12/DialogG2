# Q: посмотри по модели, где берется и обрабатывается режим сигнала пожар электрический

## Answer

Расширение: [fire,input,mode,relay,state,system]. Сигнал физического пожара задан config/lines.json как WaveShare module 1 channel 1. ModbusController опрашивает 8 DiscreteInputs модуля с базовым адресом 1 каждые 200 мс; ответ сохраняется в EngineRuntime::m_modules. LineManager::inputActive считает вход активным при установленном бите без инверсии, фильтрации или фиксации. На тике 500 мс StateEngine переводит шкаф в Fire, если fireInputActive или ручной пожар; однако отсутствие напряжения проверяется раньше и дает Emergency. Пожар блокирует/прерывает тест, передается в JSON, HMI/Web и Modbus TCP input register 4. Реле режима включается при любом режиме кроме Normal. Важные замечания: сигнал уровня не защелкивается, короткий импульс можно пропустить; при потере связи WaveShare сохраненные inputs не очищаются; при одновременном пожаре и потере напряжения HMI mode будет Emergency, а Modbus cabinet state может показать Fire.
