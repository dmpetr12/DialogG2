# LineOperationalMonitor

`LineOperationalMonitor` постоянно контролирует мощность линий в рабочем режиме. Это не тест и не пишет журнал тестов.

Правила:

```text
линия выключена
    -> Не контролируется

линия только включилась
    -> Прогрев
    -> неисправность не формируется

линия включена дольше warmupSeconds
    -> проверяем outputPower по nominalPower и powerTestTolerancePercent

нет outputPower / NaN
    -> Нет измерения
    -> LineState::Fault

мощность вне допуска
    -> Неисправность
    -> LineState::Fault
```

Для постоянных линий прогрев начинается после старта программы или после появления линии во включённом состоянии.
Для непостоянных линий контроль выполняется только когда линия включена (`outputState = On`).

Результат пишется в:

```text
lines[].operationalCheck
```

Если оперативный контроль поставил `LineState::Fault`, `StateEngine` добавит линию в `activeFaults`, и в реальном цикле это должно включить реле/лампу `Неисправность`.
