# MODBUS TCP

Движок поднимает MODBUS TCP server из секции `modbus.tcp` в `config/app.json`.

По умолчанию:

```json
{
    "enabled": true,
    "bind": "0.0.0.0",
    "port": 502,
    "serverAddress": 1
}
```

## Input registers

Адреса указаны как смещение от `30001`.

| Регистр | Смещение | Значение |
| --- | ---: | --- |
| `30001` | 0 | Шкаф включен: `1` |
| `30002` | 1 | Состояние шкафа: `0` норма, `1` пожар, `2` тест, `3` авария, `4` АКБ неисправна/нет связи, `5` АКБ разряжена |
| `30003` | 2 | Количество линий |
| `30004` | 3 | АКБ: `0` норма, `1` неисправность/нет связи, `2` предупреждение |
| `30005` | 4 | Аварийный вход: `0` нет, `1` пожар |
| `30006` | 5 | Дверь: `0` закрыта/не контролируется |
| `30007` | 6 | Система: `0` норма, `1` авария |
| `30009` | 8 | Входное напряжение, `x10` |
| `30010` | 9 | Входная мощность, `x10` |
| `30011` | 10 | Входной ток, `x100` |
| `30012` | 11 | Входная частота, `x100` |
| `30013` | 12 | Температура, `x10` |
| `30017` | 16 | Время системы Unix, low word |
| `30018` | 17 | Время системы Unix, high word |
| `30019` | 18 | Последний длительный тест Unix, low word |
| `30020` | 19 | Последний длительный тест Unix, high word |

Если измерения нет, пишется `0xFFFF`.

## Lines

Блоки линий начинаются с `30101`, по 6 регистров на линию.

| Смещение в блоке | Значение |
| ---: | --- |
| 0 | Тип: `0` отключена, `1` постоянная, `2` непостоянная |
| 1 | Состояние: `0` норма, `1` авария, `2` тест, `3` отключена |
| 2 | Выход: `0` выкл, `1` вкл, `2` неизвестно |
| 3 | Последний тест Unix, low word |
| 4 | Последний тест Unix, high word |
| 5 | Резерв |

## Coils

Команды импульсные: после записи `1` сервер сбрасывает coil обратно в `0`.

| Coil | Команда |
| ---: | --- |
| 1 | Включить ручную аварию |
| 2 | Снять ручную аварию |
| 5 | Остановить текущий тест |
| 6 | Запустить тест исправности |
| 7 | Запустить тест длительности |
