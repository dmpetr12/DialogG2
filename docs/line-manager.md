# LineManager

`LineManager` хранит карту линий и назначение входов/реле WaveShare Dual Ethernet Ports 8-ch Relay Module.
Также он хранит последние результаты тестов линий в `config/lines.json`, чтобы эти данные переживали перезапуск панели.

## Первый модуль WaveShare

Входы:

```text
1 = Пожар, по состоянию
2 = Кнопка старт ручного пожара
3 = Кнопка стоп ручного пожара / стоп теста
4 = Реле контроля напряжения
5..8 = запрос включения линий 1..4
```

Реле:

```text
1 = общее реле режима Тест / Пожар / Авария
2 = лампа Неисправность, нормально-замкнутый контакт
3 = лампа Тест
4 = резерв
5..8 = реле включения линий 1..4
```

## Следующие модули WaveShare

Входы и реле используются под линии блоками по 8 каналов:

```text
модуль 2 каналы 1..8 = линии 5..12
модуль 3 каналы 1..8 = линии 13..20
модуль 4 каналы 1..5 = линии 21..25
```

Фактическая карта хранится в:

```text
config/lines.json
```

По умолчанию в новом шкафу заведены 3 линии. Остальные добавляются через настройки панели; код поддерживает до 25 линий.
Ноль линий не считается реальной конфигурацией: при пустом списке менеджер оставляет рабочие дефолтные линии.

## Ручки для настройки линий

`LineManager` не управляет тестом, пожаром и режимами шкафа. Это слой настройки и расчета выходов линий.

Для панели и engine есть отдельные методы:

```text
lines()            = получить все линии
line(index)        = получить одну линию
makeNextLine()     = подготовить следующую линию с дефолтной привязкой WaveShare
addLine(line)      = добавить линию
removeLine(index)  = удалить линию
updateLine(line)   = заменить конфигурацию линии целиком
saveConfig(path)   = сохранить изменения в файл
applyTestResults(entries) = обновить последние результаты тестов линий по журналу
```

Панель редактирует линию как одну карточку: название, тип, включена/выключена, мощность, допуск теста, предел утечки, вход WaveShare и реле WaveShare. После нажатия "Сохранить" она передает всю `LineConfig` в `updateLine`.

## Логика

- Постоянная линия по умолчанию включена.
- Непостоянная линия включается, когда активен её назначенный вход `requestInput`.
- Факт активного входа непостоянной линии попадает в снимок как `requestInputActive`.
- Непостоянные линии не включаются вручную с экрана; их включают внешние кнопки/реле через входы WaveShare.
- Во время теста, пожара или аварии `modeRelayOn` включает общее реле режима. Линии принудительно не включаем: после переключения режима они сами переходят на резервное питание по схеме шкафа.
- Отключенная в конфигурации линия всегда выключена, даже если её внешний вход активен.
- Состояние выхода линии берём из нашей команды реле, внешнего подтверждения нет.
- Контакт входа считается активным, если соответствующий бит входов WaveShare равен `1`.
- Вход 2 попадает в `manualFireButtonActive`: это команда старт ручного пожара, а не старт теста.
- Вход 3 попадает в `manualStopButtonActive`: это команда стоп ручного пожара и стоп активного теста.
- Команды реле формируются как полный байт на модуль WaveShare: один модуль = одно значение `0x00..0xFF`.
- Низкий уровень Modbus должен писать этот байт одним запросом на 8 coil, как в старом проекте `LineIoManager -> ModbusBus::setModuleRelaysBits`.
- Реле лампы `Неисправность` инвертировано относительно желаемого света: в норме реле включено и размыкает нормально-замкнутый контакт, при неисправности реле отпущено и лампа горит. Если питание электроники пропало, реле тоже отпускает и лампа загорается аппаратно.

Первое реле первого WaveShare (`modeRelayOn`) включает общий режим Тест / Пожар / Авария:

```text
false = обычная работа
true  = общий режим Тест / Пожар / Авария
```

`LineManager` не решает сам, какой сейчас режим шкафа. Он принимает флаг общего режима и собирает выходной байт реле.

## Нумерация линий

```text
Линия 1  = модуль 1 вход/реле 5
Линия 2  = модуль 1 вход/реле 6
Линия 3  = модуль 1 вход/реле 7
Линия 4  = модуль 1 вход/реле 8
Линия 5  = модуль 2 вход/реле 1
...
Линия 12 = модуль 2 вход/реле 8
Линия 13 = модуль 3 вход/реле 1
...
Линия 20 = модуль 3 вход/реле 8
Линия 21 = модуль 4 вход/реле 1
...
Линия 25 = модуль 4 вход/реле 5
```
